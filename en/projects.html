Undergraduate capstone

Multi-Platform Attendance System Using Face Recognition

Dec 2022–Jun 2023

This undergraduate capstone project integrated identity recognition, attendance records, statistical data exports, and multi-platform access for classroom attendance. It received the Second Prize for Outstanding Undergraduate Thesis (Design), Southwest University Class of 2023.

uni-appSpring BootMySQLPythonAndroid / WeChat Mini Program / Web
Role
Project lead / end-to-end implementation
Core workflow
Image-based identification, attendance records, periodic reports

PersevereStudy
  • The system identifies students in attendance from camera-captured or uploaded images and generates attendance summaries and periodic reports.
  • It supports Android, WeChat Mini Program, and web access, allowing teachers and students to use it in different classroom settings.
  • The back end handles core business workflows, Python performs image processing, and uni-app provides a shared interface layer across platforms.
