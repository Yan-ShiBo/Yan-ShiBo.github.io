Notes

Counting rules and privacy boundaries.

  • Public statistics come from this site's own API and restart on July 22, 2026; no previous counts are imported. Only the Chinese and English home and statistics pages are tracked.
  • Devices are estimated monthly in Asia/Shanghai time. The server uses only the active month's HMAC digests for this metric and removes older digests on the first valid visit after rollover; it never stores raw network addresses or browser identifiers.
  • Shared networks and changes to browser identifiers can merge or duplicate devices, so this metric is not an exact count of people.
  • API errors or timeouts render “--”; records stored in the current browser remain available.
